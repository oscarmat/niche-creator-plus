# Niche Creator Plus

Niche Creator Plus es un plugin de WordPress diseñado para facilitar la creación y gestión de sitios web de nicho.

## Descripción

Este plugin proporciona herramientas para automatizar y optimizar la creación de sitios web de nicho, incluyendo funcionalidades para la generación de contenido, investigación de palabras clave y optimización SEO.

## Características

- Interfaz de administración intuitiva
- Herramientas para la creación rápida de sitios de nicho
- Generación de contenido optimizado para SEO
- Investigación de palabras clave
- Personalización de estilos y funcionalidades

## Instalación

1. Descarga el archivo zip del plugin
2. Ve a tu panel de WordPress > Plugins > Añadir nuevo
3. Haz clic en "Subir plugin" y selecciona el archivo zip descargado
4. Activa el plugin desde la página de plugins

## Uso

1. Una vez activado, encontrarás un nuevo menú "Niche Creator" en tu panel de administración
2. Configura las opciones básicas en la sección de configuración
3. Utiliza las herramientas disponibles para crear y gestionar tus sitios de nicho

## Requisitos

- WordPress 5.0 o superior
- PHP 7.2 o superior
